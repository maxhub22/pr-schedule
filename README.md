# ตารางงานทีมสื่อ PR SYSI (เวอร์ชัน Vercel + ล็อกอิน)

- **ทุกคนเปิดดูได้** โดยไม่ต้องล็อกอิน (ดูอย่างเดียว)
- **แก้ไขได้เฉพาะคนที่ล็อกอินด้วยรหัสผ่านกลางของทีม (รหัสเดียว)** เพิ่มงาน แก้ไข ลบ เปลี่ยนสถานะ ตั้งค่าตัวเลือก และลิงก์สำคัญ
- ตรวจสิทธิ์ที่ฝั่งเซิร์ฟเวอร์ทุกครั้ง (ไม่ใช่แค่ซ่อนปุ่ม) – ยิง API ตรงๆ โดยไม่ล็อกอินจะได้ 401
- ข้อมูลเก็บใน Upstash Redis (มีแผนฟรี) รหัสผ่านเก็บเป็น hash ไม่เก็บรหัสจริง

## โครงสร้าง
```
public/index.html   หน้าเว็บทั้งหมด
api/                Vercel Functions: data, task, config, login, logout, me
lib/                store (ฐานข้อมูล), auth (ล็อกอิน/คุกกี้), validate (ล้างข้อมูลก่อนบันทึก)
scripts/            make-password.js (สร้างรหัส), seed.js (นำเข้าข้อมูลเดิม)
data/seed.json      ข้อมูลปัจจุบัน ณ 30 ก.ย. 2569 (2 งาน + ตัวเลือก/สี/ลิงก์สำคัญ)
```

## ขั้นตอน Deploy

### 1) สร้างรหัสผ่านและคีย์
ต้องติดตั้ง Node.js (v18 ขึ้นไป) ในเครื่องก่อน แล้วรันในโฟลเดอร์โปรเจกต์:
```
node scripts/make-password.js "รหัสผ่านของทีม"
```
- รหัสผ่านอย่างน้อย 8 ตัว ตั้งให้เดายาก แล้วแจ้งให้แก่นกับแม็กรู้
- ได้ 2 ค่า: `EDIT_PASSWORD_HASH` และ `SESSION_SECRET` เก็บไว้ ห้ามส่งเข้าแชตหรือใส่ใน GitHub

### 2) ขึ้น GitHub แล้ว Import เข้า Vercel
1. อัปโฟลเดอร์นี้ขึ้น GitHub (repo แบบ private ก็ได้) – ไฟล์ `.gitignore` กันไม่ให้อัปไฟล์ลับอยู่แล้ว
2. ใน Vercel กด Add New → Project → เลือก repo นี้ → Framework Preset เลือก **Other** → Deploy
   (ครั้งแรกจะเปิดได้แต่ยังโหลดข้อมูลไม่ได้ เพราะยังไม่มีฐานข้อมูล ไปทำข้อ 3)

### 3) สร้างฐานข้อมูล Upstash Redis
1. ในโปรเจกต์ Vercel ไปที่แท็บ **Storage** (หรือ Marketplace) แล้วเพิ่ม **Upstash Redis** เชื่อมกับโปรเจกต์นี้
2. ไปที่ Settings → Environment Variables ตรวจว่ามีตัวแปรของฐานข้อมูลถูกเพิ่มอัตโนมัติ
   โค้ดรองรับทั้งชุด `UPSTASH_REDIS_REST_URL` / `UPSTASH_REDIS_REST_TOKEN` และชุด `KV_REST_API_URL` / `KV_REST_API_TOKEN`
   ถ้าไม่มีชุดใดเลย ให้สร้างฐานข้อมูลที่ upstash.com เอง แล้วคัดลอก REST URL กับ REST TOKEN มาตั้งเป็นสองตัวแปรแรกด้วยมือ
   (ชื่อเมนูและชื่อตัวแปรของ Vercel/Upstash อาจเปลี่ยนได้ ให้ยึดหน้าจอจริงและเอกสารล่าสุด)

### 4) ตั้งตัวแปรล็อกอิน
ใน Settings → Environment Variables เพิ่ม 2 ตัว (เลือกทุก Environment):
| ชื่อ | ค่า |
|---|---|
| `EDIT_PASSWORD_HASH` | ค่า hash ที่ได้จากข้อ 1 (หน้าตาแบบ `ตัวอักษรยาวๆ:ตัวอักษรยาวๆ`) |
| `SESSION_SECRET` | ค่าสุ่มที่ได้จากข้อ 1 |

จากนั้นไปแท็บ Deployments → Redeploy เพื่อให้ตัวแปรมีผล

### 5) นำข้อมูลเดิมเข้า (ทำครั้งเดียว ข้ามได้ถ้าจะเริ่มใหม่)
รันในเครื่อง โดยตั้งค่าฐานข้อมูลชั่วคราวในเทอร์มินัลนั้น (ค่า URL/TOKEN ดูจากหน้า Upstash หรือ Vercel):
```
# macOS / Linux
UPSTASH_REDIS_REST_URL="https://..." UPSTASH_REDIS_REST_TOKEN="..." node scripts/seed.js

# Windows PowerShell
$env:UPSTASH_REDIS_REST_URL="https://..."; $env:UPSTASH_REDIS_REST_TOKEN="..."; node scripts/seed.js
```
สคริปต์จะไม่เขียนทับถ้าในฐานข้อมูลมีงานอยู่แล้ว (ต้องใส่ `--force` เอง)

### 6) ทดสอบ
- เปิดลิงก์ `.vercel.app` ในหน้าต่างที่ไม่ได้ล็อกอิน ต้องเห็นตาราง และไม่มีปุ่มเพิ่มงาน/ตั้งค่า
- กด 🔒 ล็อกอิน ใส่รหัสผ่านของทีม แล้วลองเพิ่ม แก้ไข ลบงาน
- เปิดอีกเครื่องพร้อมกัน หน้าจอจะดึงข้อมูลใหม่เองทุก 20 วินาที (ไม่ใช่เรียลไทม์ทันที)

## การใช้งานทั่วไป
- **เปลี่ยนรหัสผ่าน:** รัน `make-password.js` ด้วยรหัสใหม่ → แก้ค่า `EDIT_PASSWORD_HASH` ใน Vercel → Redeploy (ทุกเครื่องที่ล็อกอินค้างอยู่จะถูกออกจากระบบทันที ต้องล็อกอินด้วยรหัสใหม่) ไม่ต้องแก้ `SESSION_SECRET`
- **ต้องการเตะคนที่รู้รหัสออก:** เปลี่ยนรหัสตามข้างบน เพราะเป็นรหัสกลาง ระบบไม่รู้ว่าใครเป็นใคร ไม่มีประวัติว่าใครแก้อะไร
- **ลืมรหัส:** ไม่มีระบบรีเซ็ตอัตโนมัติ ให้สร้างรหัสใหม่ตามข้างบน
- **เปลี่ยน SESSION_SECRET:** ทุกคนจะถูกออกจากระบบและต้องล็อกอินใหม่
- ล็อกอินค้างได้ 30 วันในเบราว์เซอร์นั้น ผิดรหัสเกิน 8 ครั้งใน 15 นาทีจะถูกบล็อกชั่วคราว

## ข้อควรรู้
- **ทุกคนที่ได้ลิงก์เห็นข้อมูลทั้งหมด** รวมหมายเหตุ ลิงก์งาน และลิงก์สำคัญ อย่าใส่ข้อมูลลับในช่องเหล่านี้
- แผน Vercel Hobby (ฟรี) ระบุให้ใช้เพื่อการส่วนตัวที่ไม่ใช่เชิงพาณิชย์ ถ้าใช้ในนามองค์กร ให้ตรวจนโยบาย fair use ของ Vercel ก่อน
- แก้พร้อมกันหลายคน: บันทึกทีละงาน ไม่ทับกันทั้งตาราง แต่ถ้าสองคนแก้งานเดียวกันพร้อมกัน คนบันทึกทีหลังจะทับ
- ตัวเลือก/สี/ลิงก์สำคัญเก็บเป็นชุดเดียว คนบันทึกทีหลังทับคนก่อน (ปกติแก้นานๆ ครั้ง)

## รันทดสอบในเครื่อง (ไม่บังคับ)
`npx vercel dev` จะรันหน้าเว็บ+API ในเครื่อง ถ้าไม่ตั้งค่าฐานข้อมูล ระบบใช้หน่วยความจำชั่วคราว (ข้อมูลหายเมื่อปิดโปรแกรม) ต้องตั้ง `EDIT_PASSWORD_HASH` และ `SESSION_SECRET` ในไฟล์ `.env.local`
